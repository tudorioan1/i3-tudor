# i3-tudor
# Note : This might need additional troubleshooting (it is not tested)
My i3 dotfiles with polybar, dunst, picom, rofi.

1. Install the required dependencies : i3, picom, dunst, rofi, polybar, flameshot, thunar, alacritty, quickshell.
2. Clone the repository into your .config directory on your linux system.
3. Move the "polybar-i3" directory into the i3 config directory after cloning in .config.

Launch i3 from your display manager (SDDM, GDM, LightDM, Ly etc.) and enjoy.
